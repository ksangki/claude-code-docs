Claude Code 사내 교육 슬라이드

Claude Code 공식 한글 문서(Ch.01~20)를 실무자용 강의 슬라이드로 재구성한 자료입니다. 챕터를 클릭하면 브라우저에서 바로 슬라이드가 시작됩니다.

총 20개 챕터 Marp로 빌드 방향키 / 스페이스로 이동

사용법

슬라이드 탐색

  • 오른쪽 화살표 또는 스페이스바: 다음 슬라이드
  • 왼쪽 화살표: 이전 슬라이드
  • F: 전체화면 (Marp HTML)
  • ESC: 전체화면 종료

소스와 다른 포맷

이 사이트는 Marp Markdown을 HTML로 빌드한 결과입니다.

  • Marp Markdown 소스: slides/marp/*.md — 저장소에서 직접 편집 가능
  • Google Apps Script: slides/apps-script/*.gs — script.google.com에서 실행하면 동일한 내용을 Google Slides로 직접 생성
  • README: slides/README.md — 포맷별 상세 사용법
💡 PPTX 필요하시면: 로컬에 npm install -g @marp-team/marp-cli 후 marp slides/marp/01-introduction.md -o ch01.pptx 로 변환 가능합니다.
