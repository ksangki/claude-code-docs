# Ch.07 도구 목록

**내장 도구 전체 레퍼런스**

실무자 과정 · 사내 교육 자료

## 학습 목표

- **파일 도구 4종** (`Read`, `Edit`, `Write`, `Glob`)
- **셸 도구** (`Bash`) 복합 커맨드·백그라운드 실행
- **검색 도구 2종** (`Grep`, `LS`)
- **웹 도구 2종** (`WebFetch`, `WebSearch`)
- **에이전트 도구 2종** (`Task`, `TodoWrite`)

- 노트북 도구 (`NotebookEdit`)
- 도구 가용성 제어 방법

---

## 파일 도구: `Read`

**로컬 파일시스템 파일 읽기.**

- 기본 최대 **2,000줄**
- `offset`, `limit` 지원 → 대용량 파일 타겟 읽기
- 출력 형식: `cat -n`처럼 **줄 번호 포함**
- 지원 타입:
  - **이미지** (PNG, JPG 등)
  - **PDF** (한 번에 최대 20페이지)
  - **Jupyter 노트북** (`.ipynb`)

**권한**: 읽기 전용 → **항상 자동 승인**.

---

## 파일 도구: `Edit`

**정확한 문자열 교체.**

- **`Read` 먼저 필수** — 같은 대화에서 읽지 않으면 실패
- `old_string` → `new_string` 교체
- `old_string`은 파일에서 **유일해야 함**
- `replace_all: true` → 파일 전체에서 이름 변경 (변수명 리팩터링 등)

**실패 조건**: `old_string`이 두 번 이상 나타나면 실패 (`replace_all`이 없을 때).

---

## 파일 도구: `Write`

**새 파일 생성 또는 완전 덮어쓰기.**

- 기존 파일 수정 시에는 **먼저 `Read` 필요**
- 기존 파일 수정에는 **`Edit` 선호**
- `Write`는 전체 파일 내용을 **매번 전송** → 작은 변경에 비효율
- **새 파일** 또는 **전체 재작성**에 적합

---

## 파일 도구: `Glob`

**파일 이름 패턴 검색.**

- 어떤 코드베이스 크기에서도 **빠른 매칭**
- 수정 시간 기준 정렬된 경로 반환
- 지원 패턴:
  - `**/*.ts`
  - `src/**/*.test.js`
  - `**/CLAUDE.md`

**권한**: 읽기 전용 → **항상 자동 승인**.

---

## 셸 도구: `Bash`

**대화 내 지속되는 셸 세션에서 커맨드 실행.**

- 도구 호출 간 **환경 변수·작업 디렉토리 유지**
- `timeout` 파라미터 지원

**주요 동작:**

- **복합 커맨드** (`&&`, `||`, `;`, `|`) → 서브커맨드 **독립 검사**
- **백그라운드 실행** → `run_in_background: true`
- **출력 제한** → 예산 초과 시 미리보기 + 파일 경로

> **팁**: 콘텐츠 검색은 `Bash(grep)` 대신 **전용 `Grep` 도구** 사용.

---

## 검색 도구: `Grep`

**정규식 파일 내용 검색 (ripgrep 기반).**

**기능:**
- 전체 **regex 구문**
- 파일 타입 필터 (`*.ts`, `**/*.py`)
- 세 가지 **출력 모드**

| 모드 | 반환 |
|---|---|
| `files_with_matches` (기본) | 파일 경로만 |
| `content` | 매칭 줄 + 컨텍스트 |
| `count` | 파일당 매칭 수 |

- `multiline: true` → 멀티라인 패턴

**권한**: 읽기 전용 → **항상 자동 승인**.

---

## 검색 도구: `LS`

**디렉토리 내용 나열.**

- 구조화된 형식으로 파일/서브디렉토리 반환
- 파일 읽기/편집 **전에 구조 탐색**에 유용
- 읽기 전용 → 항상 자동 승인

**활용 패턴:**
1. `LS` → 프로젝트 구조 파악
2. `Glob` → 특정 패턴 파일 목록
3. `Grep` → 내용 검색
4. `Read` → 대상 파일 집중 읽기

---

## 웹 도구: `WebFetch`

**URL에서 정보 가져오기.**

- HTML → 마크다운 변환
- 보조 모델로 **집중된 답변 생성**
- HTTP → **자동 HTTPS 업그레이드**
- **15분 자가 정리 캐시**
- 리다이렉트 시 **새 호스트 URL 반환**
- GitHub URL은 **`gh` CLI + Bash** 권장

**권한**: `default` 모드에서 **승인 요청**.

---

## 웹 도구: `WebSearch`

**웹 검색 결과 반환.**

- 제목, 스니펫, URL을 **마크다운 링크**로 형식화
- 훈련 컷오프 **이후 정보 접근**에 유용
- 응답 후 `Sources:` 섹션에 URL 자동 나열
- **현재 미국에서만** 이용 가능
- `default` 모드에서 승인 요청

**사내 활용**: 최신 라이브러리 버전 확인, 이슈 링크 추적.

---

## 에이전트 도구: `Task` (Agent)

**서브에이전트 생성.**

별도 컨텍스트에서 시작하는 서브에이전트:
- **자체 대화 기록**
- (선택) **제한된 도구 집합**
- 완료 후 결과를 부모에 반환

**실행 위치:**

| 위치 | 설명 |
|---|---|
| **로컬** | 인프로세스, 파일시스템/셸 공유 |
| **원격** | 원격 에이전트 기준 충족 시 별도 컴퓨팅 |

**언제 사용**: 개방형 검색, 병렬 워크스트림, 격리된 서브 문제.

---

## 에이전트 도구: `TodoWrite`

**작업 목록 관리.**

- 상태: `pending`, `in_progress`, `completed`
- 터미널 UI **영구 패널**에 표시
- Claude가 **복잡한 다단계 작업의 진행**을 추적

**사용 기준**: 3개 이상의 별개 단계가 있는 작업에 적극 사용.

**사내 효과**: 리팩터링, 마이그레이션, 릴리즈 작업에서 **진행 가시성** 확보.

---

## MCP 도구

**Model Context Protocol 서버가 노출하는 도구.**

- 연결된 도구는 **내장 도구와 함께** 목록에 나타남
- **동일한 권한 시스템** 적용

**네이밍 규칙:**

```
mcp__<server-name>__<tool-name>
```

예: `mydb` 서버의 `query` → `mcp__mydb__query`

**일반적 범주:**
- DB 쿼리/관리
- 브라우저·웹 자동화
- 클라우드 API (AWS, GCP, Azure)
- 이슈 트래커 (GitHub, Linear, Jira)
- 사내 도구 API

---

## 노트북 도구: `NotebookEdit`

**Jupyter 노트북(`.ipynb`) 편집.**

- **셀 단위** 삽입/교체/삭제
- 줄 단위 정밀도
- 노트북 **읽기**는 표준 `Read` 도구 사용 (모든 셀 + 출력 반환)

**활용**: 데이터 분석, ML 실험, 교육 자료 관리.

## 도구 가용성 제어

모든 도구가 모든 상황에서 쓸 수 있는 것은 아님.

| 제어 | 효과 |
|---|---|
| `CLAUDE_CODE_SIMPLE=1` | `Bash`, `Read`, `Edit`만 활성 |
| 권한 차단 규칙 | 포괄 차단된 도구는 **모델이 보기 전에** 목록 제거 |
| `isEnabled()` 검사 | 각 도구가 환경 조건 따라 **자가 비활성** |
| MCP 서버 연결 상태 | 서버 실행 + 연결된 경우에만 이용 |

**확인 방법**: REPL에서 `/tools`

## 도구 선택 가이드

| 작업 | 선호 도구 |
|---|---|
| 파일 위치 찾기 | `Glob` |
| 내용 검색 | `Grep` (not `Bash(grep)`) |
| 파일 구조 파악 | `LS` → `Glob` |
| 읽기 | `Read` (대용량은 `offset/limit`) |
| 기존 파일 수정 | `Edit` (not `Write`) |
| 새 파일 | `Write` |
| 여러 독립 작업 | `Task` 서브에이전트 병렬 |
| 다단계 진행 | `TodoWrite` |
| 웹 데이터 | `WebFetch` / `WebSearch` |

---

## 사내 가이드라인 제안

- `Read/Grep/Glob/LS`는 **전역 allow** → 탐색 쾌적
- `Edit/Write`는 **프로젝트별 allow** 또는 `acceptEdits`
- `Bash`는 **세분화 패턴 allow** (git, npm 등)
- `WebFetch`/`WebSearch`는 **민감 데이터 주의**
- MCP 도구는 **서버별 allow/deny** 관리
- 노트북은 **실험 데이터 커밋 전 검증**
